## 🧐 Problem Statement

Women face a rising number of digital threats such as stalkerware, cyber harassment, non-consensual image sharing, and privacy breaches. Existing tools are fragmented, reactive, and often hard to use. There's an urgent need for a simple, proactive solution tailored for women’s digital safety.

---

## 💡 Solution Overview

**Cyra** provides an AI-powered app that:
- Detects stalkerware and app-level privacy threats
- Offers live SOS and offline emergency features
- Scans the web for misused personal content
- Helps secure social accounts and device permissions

Cyra is private, intelligent, and easy to use.

---

## ⭐ Key Features

### 1. Stalkerware & Threat App Detector
- Detects apps with excessive or dangerous permissions
- Flags stalkerware using known databases (EFF, AV vendors)
- Summarizes privacy risks via LLM (like GPT or Gemini)

### 2. Real-Time Emergency Button
- Sends live location & device info to trusted contacts
- Triggers fake call or blackout screen
- Offline fallback via SMS

### 3. Deepfake & Image Abuse Detector
- AI-based image search for abuse or reposts
- Alerts users about flagged content
- One-tap takedown request generation

### 4. Privacy Fix Toolkit
- Revoke dangerous app permissions
- Lock down social profiles
- Generate & securely store strong passwords
